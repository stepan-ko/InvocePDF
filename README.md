
# PDF Generator Счета/Акта

Веб‑сервис для генерации PDF‑документов (счетов и актов) на базе ASP.NET.

Доступен [тут](http://135.106.196.190:8080)  

## Функционал

- **Ввод данных**: пользователь заполняет поля формы для акта или счёта.
- **Генерация PDF**: сервер формирует готовый PDF‑документ (счёт или акт) на основе введённых данных.
- **Локальное хранение**: все введённые данные сохраняются в `localStorage` браузера пользователя — это позволяет вернуться к черновику без потери информации даже при обновлении страницы.

## Технологии

- ASP.NET (бэкенд);
- PDF‑генерация на стороне сервера;
- Сохранение введенных данных в SQLite на сервере
- Браузерный `localStorage` для временного хранения данных.

## Как запустить

1. Клонируйте репозиторий.
2. Откройте проект в Visual Studio / через CLI.
3. Выполните сборку: `dotnet build`.
4. Запустите проект: `dotnet run`.
5. Откройте в браузере адрес, указанный в консоли.

## Примеры использования

Пользователь вводит:
- реквизиты контрагента,
- перечень товаров/услуг,
- суммы и НДС,
- дополнительные примечания.

После нажатия кнопки «Скачать» сервер генерирует PDF и происходит загрузка файла.
